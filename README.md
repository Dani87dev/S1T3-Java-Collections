# SPRINT1.03 Java Collections

In this task, we practice using the most useful classes from the Java Utilities library to improve our understanding and practice
of how these data structures are created, modified, and traversed.

---

## TASK 1 — LEVEL 1

### 📌 Exercise Statement

**Exercise 1 — ArrayList, HashSet and Iterator**

1. Create a `Month` class with the `name` attribute and add 11 `Month` objects to an `ArrayList`, leaving out **August**.
2. Insert this month into the correct position and verify that the order of the months is correct.
3. Convert the `ArrayList` into a `HashSet` and verify that duplicate elements are not allowed.
4. Traverse the collection using a `for-each` loop and an `Iterator`.

---

## TASK 2 — LEVEL 1

### 📌 Exercise Statement

**Exercise 2 — ListIterator**

1. Create and populate a `List<Integer>`.
2. Create a second list and insert the same elements in **reverse order**.
3. Use a `ListIterator` to read the elements of the first list and add them to the second list in reverse order.

This exercise focuses on practicing the use of `ListIterator`, particularly its ability to traverse a list backwards using
`hasPrevious()` and `previous()`.

---

## TASK 3 — LEVEL 1
📌 Exercise Statement

Exercise 3 — Capital Game

Read the file countries.txt and store the country–capital pairs in a HashMap.

Ask the user for their name.

Randomly select 10 different countries.

Ask the user for the capital of each country and calculate the score.

Display the final score and save the user name and score in classificacio.txt.
